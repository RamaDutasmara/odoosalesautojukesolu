# Odoo Sales Automation Test

Repository ini berisi **contoh automation test** yang dibuat sebagai **nilai tambah** untuk QA Assessment, dengan fokus pada **modul Sales – Customer dan Product** pada aplikasi Odoo.

Automation test disusun berdasarkan test scenario dan test case yang telah dibuat sebelumnya.

---

##  Application Under Test
- Platform: Odoo (Web-based ERP)
- Module: Sales
- Features:
  - Customer Management
  - Product Management

---

##  Objective
Tujuan dari automation test ini adalah untuk:
- Menunjukkan pemahaman konsep automation testing
- Menyediakan contoh implementasi automation test untuk fungsi utama
- Menunjukkan pemilihan test case yang tepat untuk regression testing

---

## 🔍 Automation Scope
Automation test difokuskan pada fungsi utama yang paling sering digunakan, yaitu:

### Customer
- Create Customer 
- Update Customer 

### Product
- Create Product 
- Update Product Price
